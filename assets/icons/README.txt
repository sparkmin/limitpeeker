LimitPeeker - service logos
===========================

The logos of the services are their companies' trademarks, so LimitPeeker
does not include them. Without a logo here, each service is drawn as a dot
in its own color.

To show a logo, put an .svg or a .png file in this folder, named after the
service:

    gpt.svg       Codex (ChatGPT)
    claude.svg    Claude
    gemini.svg    Gemini (Antigravity)
    grok.svg      Grok

(or gpt.png, claude.png and so on). A logo in one color is painted in the
service's color. PC needs no file; LimitPeeker draws it.

A logo put in, changed or taken away shows in the boxes within a second,
and in the popup the next time it opens. The settings window's Boxes page
opens this folder with Open icons folder.

Updating LimitPeeker replaces this note but keeps the logos you put here.
